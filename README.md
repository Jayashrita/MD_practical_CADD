# MD_practical_CADD
Colab notebook on hands on MD tutorial
Updated

This tutorial should guide you on how to run your first MD simulation for a protein-ligand system.

To follow the tutorial:
1) Open the notebook on Colab
2) Download the PDB files and upload them to your GoogleDrive. Create a separate folder on drive for each run. ~100 MB of free space might be necessary. More memory might be required for longer simulations

Objectives of this tutorial or guidelines for report:
1. Give an overview of all the things that should matter while running Molecular dynamics simulations
- Choice of forcefields, time steps, integrators, temperature, pressure, volume of box, PBC
- How do you enforce constant temperature or pressure
- How does equilibration protocol influence simulation? Why should you equilibrate.
2. Find out which protein residues are interacting with the ligand.
3. How does simulation temperature influence ligand unbinding and protein conformational changes?
4. What kind of quantitative analysis would give you some idea about the effect of temperature?
